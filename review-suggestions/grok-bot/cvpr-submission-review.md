## 3. 按审稿项逐条意见

### 3.1 是否适合 CVPR（视觉相关性）

**结论：当前叙事对 CV 社区不够有说服力，属于“用视觉数据集包装的转换方法文”，而不是一篇视觉系统或视觉表示论文。**

稿件的切入点是：ANN-to-SNN 理论几乎全在行随机卷积算子上发展，作者把一套图节点分类转换框架迁到超级像素图分类。动机里引用了 Vision GNN（ViG，Han 等，NeurIPS 2022）和 Benchmarking GNNs 的超级像素设定，这在方向上说得通——CVPR 的 “Efficient and scalable vision” 主题可以容纳事件驱动视觉推理。

但审稿人会立刻看到：

- 实验只有 SuperPixel MNIST / CIFAR10 上的**两层窄 GCN**。正文教师精度为 MNIST **34.02±1.60%**、CIFAR10 **27.27±1.67%**（Table 1）。作者自己承认“不是有竞争力的分类器”，却把 20%（随机的两倍）当作可接受下限。对 CVPR 来说，用远低于像素 CNN、也远低于公开超级像素 GNN 成绩的教师，去讨论“图结构视觉”，很难成立。公开 Benchmarking GNNs 成绩是 MNIST GCN 90.705%、GatedGCN 97.340%，CIFAR10 GCN 55.710%、GatedGCN 67.312%（[JMLR 2022](https://www.jmlr.org/papers/volume24/22-0567/22-0567.pdf)，[leaderboard](https://github.com/graphdeeplearning/benchmarking-gnns/blob/master-may2022/docs/07_leaderboards.md)）。仓库后来已经把教师做到这一量级，但**本稿没有用这些数字**。
- 引用了 ViG、CIFAR10-DVS、事件相机文献，却没有任何对应实验。审稿人会问：为何不在 ViG 或事件流视觉上验证，而停在 75 / 150 节点的 SLIC 图上？
- 动态门控、注意力、真实视觉图被正文自己写成“失效边界”和“未来工作”。CV 审稿人关心的恰恰是这些更接近现代视觉骨干的算子。
- 即使换成仓库已核验的强教师数字（CIFAR10 GatedGCN 约 68.8%，与公开 67.3% 同量级；MNIST GCN 约 91%），超级像素 CIFAR 仍明显弱于像素 CNN。这可以作为方法测试床，但单独撑不起“图结构视觉转换”的 CVPR 贡献，除非再加更强的视觉骨干或明确的事件视觉任务，并展示对 CV 有用的精度–延迟–能耗权衡。

**审稿句式会类似：** *The vision motivation is asserted rather than demonstrated. Results on weakly trained two-layer superpixel GCNs, with teacher accuracy in the mid-20s to mid-30s, do not speak to graph-structured visual recognition as practiced in this community.*

### 3.2 声称的贡献 vs 仓库证据

稿件列出四项贡献。作为审稿人，我会认为**前两项至多是有限的机制观察，后两项被仓库后续核验所否定，不能按现在的写法投稿。**

**贡献 1：图级读出下的精确误差恒等式 \(\hat B-B=RA(E_1W_2)\)，float64 残差至 \(1.21\times10^{-14}\)。**  
在固定非负线性 \(A\) 与线性 \(R\) 下，这是线性性的直接推论。验证到机器精度、并澄清 float32 假残差，有方法学价值，但作为 CVPR 的首要贡献偏薄。仓库 `docs/METHODS.md` 也写了：恒等式本身不能证明表示接近、分类正确、基线更强或成本更低。此外，同一仓库后来发现旧解码在 \(\theta\neq 1\) 时未乘 \(\theta\)：恒等残差可以近零，却保不住所声称的教师关系。本稿没有把这一限制写清楚。

**贡献 2：确定性两阶段排程下，\(\beta^\star=\theta/(2T)\) 成为有害的双重校正。**  
这可以是一个干净的机制点，但范围很窄。仓库日志区分了“先定总 count 再离线排程”与因果 IF；若两阶段本就精确实现目标计数，它与在线 IF 的偏置修正不是同一对象。Table 3 中 “Naive IF phase” 与 “Full combination” 的 MNIST / CIFAR10 数字**完全相同**（65.79% / 34.10%）。审稿人会认为这项消融无效，或实现与正文声称的“两阶段”并未分开。更严重的是下面的表间矛盾。

**贡献 3 与 4：20 个种子、两组能量约定均超过 5×；基线接近随机；以及精度–能量前沿（含负的训练预算结果）。**  
这些是稿件的经验核心，也是最不能投稿的部分。仓库 `docs/OVERVIEW.md`、`docs/RESEARCH_LOG.md` 和 `paper/historical-draft/README.md` 已记录：

- 教师远弱于适用参照，能量优势主要来自把网络削窄、并把 \(T\) 压到 2–4，而不是转换算法本身的效率。
- 所谓互不相交的 holdout，跨 seed 测试子样本大量重叠，且未保存真实样本 ID；不能再称“独立、未触碰的测试”。
- 被命名为 QCFS / FTBC / TPP / parallel 的对照部分只是近似实现，读出还不同，不能冒充原作者算法。
- 成本账漏掉首次模拟计算与图算子；45 nm 操作计数不是硬件测量（稿件摘要承认了最后一点，但仍把 5× 写成稳定结果）。
- \(\theta\)、gauge、mask 首次更新等问题随后被定位，进一步削弱对旧跑数的信心。

**表间不一致（审稿人不必读仓库也能发现）。** Table 1 的 MNIST 教师为 34.02%，转换损失 3.79 pp，按常规理解转换精度应约为 30%。Table 2 的 “Ours” 在 MNIST \(T=8\) 为 **65.79%**，Table 3 “Full combination” 同为 65.79%。转换结果比自己的教师高出三十个百分点，又没有解释这是不同工作点、不同宽度还是不同划分。这足以让审稿人怀疑整张主表的口径。CIFAR10 同样：教师 27.27%、损失 1.57 pp，与 “Ours” 34.10% 对不上（\(27.27-1.57\approx 25.7\)，不是 34.10）。

把已知不可靠的 5×、接近随机的不忠实基线、以及自相矛盾的主表投出去，不只是“分数低”的问题，而是完整性和可信度问题。

### 3.3 新颖性（对照已核验的先前工作）

我会给出 **novelty: borderline to limited**，并要求改写相关工作中已不成立的句子。

- **DCGS**（Huang 等，ICML 2025，[PMLR](https://proceedings.mlr.press/v267/huang25i.html)）被引为 [17]，但只作为“文献语境、不进入主比较”，理由是官方代码“不经重新设计无法迁移”。对 CVPR 审稿人，这不是免于比较的充分理由：差分编码正是后来仓库主线真正用的源单元。本稿把主方法写成自有的“组合迁移”，却不与 DCGS 做忠实对照，新颖性陈述不完整。编译 PDF 中 [17] 的作者写作 “Yufei Huang”，初级来源为 **Zihan Huang** 等，这是引用审计已经指出的元数据错误。
- **One-Spike SNN**（Hwang & Kung，IEEE TETC 2025，[DOI](https://doi.org/10.1109/TETC.2024.3386893)，[arXiv:2403.08786](https://arxiv.org/abs/2403.08786)）已被引为 [18]，并且论文在相关工作中承认它把 Text GCN 转成了 SNN。但引言 / 相关工作仍有“据我们所知，尚无工作把完整转换误差表述迁到图级视觉分类并与一整族转换基线比较”这类句子。更关键的是，仓库引用审计明确警告：不能再写“没有已发表的 GCN 转换”。One-Spike 在五个文本图基准上平均损失 0.90%（\(T=16\)），并给出了理论能量比。本文必须把它当作直接相关工作，并在同一教师上比较，而不是用任务差异一笔带过。PDF 将第一作者写成 “Sangyeob Hwang”，可核验来源为 **Sangwoo Hwang**。
- **QCFS**（Bu 等，ICLR 2022）与 **FTBC**（Wu 等，ECCV 2024）出现在 Table 2，但仓库认为实现不忠实。接近随机的分数（QCFS MNIST \(T=8\) 为 12.50%，CIFAR 约 10%）会让熟悉这些方法的审稿人起疑：在 CNN 上它们并非如此失效。不忠实的弱对照不能支撑“图消息传递暴露了卷积转换方法的失败模式”这一强断言。
- 直接训练的脉冲 GNN（以及 [SGNNBench](https://arxiv.org/abs/2509.21342)）几乎只作为“技术族控制缺失”的旁白。稿中称 SGNNBench“不含转换方法”，仓库审计要求按全文再核，不能直接当事实。
- 误差恒等式、膜电位读出、阈值平衡、闭式偏置，正文自己承认都有谱系。剩下的“组合在新算子上的再识别”在教师过弱、基线不忠实、且动态视觉算子被排除之后，不足以达到 CVPR 的新颖性门槛。

仓库后来的真实进展——强教师上 DCGS 源单元图适配在 \(T=4/8\) 近乎保真，以及尚未验收的 affine-base 候选——**不在本稿中**。即便写入，前者首先是适配与可行性，后者还没有验证集 / 测试集与效率证据。都不能在 4 天内改写成一篇有新颖性优势的 CVPR 方法文。

### 3.4 缺失的基线与数据集

**基线（正文已点名却未忠实比较，或应补而未补）：**

- 官方 DCGS 转换流程（含阈值迭代），而不是“无法迁移所以不算”。
- One-Spike 的官方或严格复现，用在同一超级像素教师上。
- 作者代码级的 QCFS、FTBC，以及 Parallel Conversion（Hao 等，ICML 2025，稿中已引）。
- 同一骨干、同一 \(T\) 上直接训练的替代梯度脉冲 GNN。
- 像素 CNN 的成熟转换（同一图像、同一 \(T\)）作为视觉参照，说明超级像素图路径相对标准视觉转换的利弊。
- 仓库后来的 learned-init 对 FTBC 已是负结果，说明“只比一个近似 FTBC”也不够。

**数据集 / 模型：**

- 只有 SuperPixel MNIST 与 CIFAR10；没有 PATTERN / CLUSTER 等同系列基准，没有 OGB，没有 ImageNet 级视觉，没有 ViG 等视觉 GNN，没有事件相机数据集（尽管参考文献里有）。
- 没有 GatedGCN、GAT、GIN。失效边界停留在口头上。
- 训练子集在第四组 holdout 里是 2,000–3,000 张图，而官方训练集是 55k / 45k。审稿人会把它看成 toy 设定。仓库全量强教师实验已经否定了“必须用极窄、极小数据才能谈转换”的隐含前提，本稿未反映这一点。

### 3.5 应有却不足的消融

现有 Table 3 含 \(\beta^\star\)、count 读出、随机第二阶段、Naive IF。方向与机制叙述一致，但：

- “Naive IF phase” 与满分组合数字相同，该项没有信息量。
- 没有在**固定教师、固定宽度、固定 \(T\)** 下单独打开 / 关闭 margin、mask 宽度、膜读出、排程类型（离线 vs 因果 IF）。
- 没有把能量优势分解为“变窄”与“转换算法”两部分。正文讨论已经承认两者缺一不可；那正好应该做成主消融：同一转换、把宽度拉到公开 100k 参数设定后，5× 是否还在。仓库的后续证据强烈暗示：教师变强、网络变宽之后，旧的 5× 主张不再成立。
- 没有算子消融（固定 \(A\) vs 动态门）。
- 没有校准预算、阈值来源（训练 vs 误用测试）的隔离——仓库后来还修过校准泄漏类问题。

### 3.6 能量与延迟主张

这是我会标成 **overclaim / insufficient evidence** 的部分。

- 5× 建立在 45 nm Horowitz 表（MAC 4.6 pJ、AC 0.9 pJ，比值约 5.11）上的操作计数。正文承认不是硬件测量，也忽略膜更新、访存和事件路由。在比值只有 5.11 时，要报 5× 几乎必须让 SNN 操作数低于 ANN 的 MAC。这使结果对“计不计某些项”极度敏感。仓库后来补记的漏项（首层模拟、图算子、门控、BN）会改变结论。
- 能量优势明确依赖窄网络（10–26 个存活隐单元）和 \(T\in\{2,3,4\}\)。这更像是“缩小模型再换一种计数单位”，而不是转换带来的系统级效率。与公开约 100k 参数的超级像素 GNN 比，设定不在同一精度量级。
- 没有任何墙钟、端到端延迟（稿件把 \(T\) 当作延迟代理）、访存或神经形态芯片数据。
- 仓库对后续稠密差分混合的核算是：执行的稠密线性 MAC 约为 `embedding + T * body`，在 \(T=4/8\) 上大约是 ANN 的 4 倍 / 8 倍（`gated-differential-dense-cost-v1.md`）。这与本稿 5× 优势的叙事直接冲突——当然，那是不同实现；但也说明：**一旦教师和实现变完整，成本方向可能反转**。把旧 5× 在不披露这些后续核算的情况下投出，不妥当。
- 补充材料即使补上新的成本表，按 2027 政策也不能用“改进后的方法结果”或“修正后的正文 PDF”来挽救已提交的主张。

### 3.7 图与表

- **Table 1–3 口径冲突**（见 3.2）是致命的。不修正就不能投。
- Table 2 全部基线接近随机（约 10–18%），“Ours” 领先 43.67 / 19.85 pp。在审稿人眼里这更像实现失败，而不是科学发现，除非用官方代码复现并解释失败机制。
- Table 4 的机器精度恒等在数学上成立，但对 CVPR 贡献的说服力有限，且不能替代分类与能量证据。
- Figure 1（Pareto）和 Figure 2（loss–\(T\)）是合适的图类型，也纳入了负的训练预算结果，这一点是好的。问题是数据来自已不可靠的实验；从 PDF 文本提取的横轴刻度也显得拥挤、难读（\(2\times10^0\) 到 \(10^1\) 的标记在抽取中出现粘连）。两张图都基于验证网格，却用来支撑对测试 holdout 的 5× 叙述，需要把“选点只在验证、测试只报告一次”做更硬的分离——而仓库已发现测试暴露与重叠。
- `framework.pdf` 已画好却未进入稿，方法节缺少一张把恒等式、排程、读出和能量约定画在一起的示意图。对 CVPR 来说，这是不必要的表达损失。
- 没有把仓库现有的 `figures/teacher_fidelity.png`（强教师 \(T=4/8\) 保真）纳入。那张图才是目前最站得住的经验结果，但它支持的是另一项、更窄的主张，不能用来给本稿的 5× 背书。

### 3.8 写作与结构

英文总体通顺，结构符合 CVPR 短文习惯（引言四贡献、相关工作、方法、实验、讨论、结论），语气在摘要里对“能量是理论估计”有所克制。主要问题不是语法，而是**主张与证据的对齐**：

- 摘要和结论几乎全文重复 5×、20 seed、基线接近随机，把最不稳的结果放在最显眼的位置。
- 相关工作信息密度高，但若干条目的身份与支持关系已被 `paper/reference-audit/reference-truth-audit-v6.md` 质疑（42 条中 16 条元数据一致、21 条需改、5 条未解决；`dualphase2024` 不支持稿中解码等式；`bojkovic2024ot` 未找到匹配主键）。编译 PDF 里 Maass (1997) 缺期刊名，只剩页码与年份。
- 方法节对恒等式和能量公式写得清楚，但对“离线排程 vs 因果 IF”、mask 如何在训练中生效、以及工作点如何只在验证上选择，写得不够让人复现。
- 讨论的“威胁效度”段其实已经预告了弱教师、固定 \(A\)、非硬件能量等限制；审稿人会认为这些限制已经大到动摇贡献 3 和 4，而不是只需一句 limitation。
- 全文约 5 页正文 + 2 页文献，低于 8 页上限，却把关键对照和消融挤在四张小表里。不是“写太长”，而是**空间没有用在必须讲清的口径与限制上**。

## 5. 怎样才算“有竞争力”的最低实验集

下面是面向**下一次** CV 或顶级 ML 会议、而不是未来 4 天的最低集合。全部完成后仍需完全重写文稿，不能在本稿上打补丁。

1. **教师必须达到公开视觉图基准量级**，并报告与 Benchmarking GNNs 的差距。至少：全量 SuperPixel MNIST / CIFAR10；固定 GCN 与 GatedGCN（含目前缺失的 MNIST GatedGCN，公开约 97.3%）；三种子；官方完整划分。仓库已有大部分，只需补齐并写入新稿。
2. **忠实基线，同一教师、同一 \(T\) 网格、同一读出与校准隔离：** 官方 DCGS（能接则接，不能则写清失败边界）、One-Spike、作者代码级 QCFS 与 FTBC、至少一种直接训练脉冲 GNN。禁止再使用本稿 Table 2 的近似实现与数字。
3. **一项可分离的方法贡献，且有验证集锁定、测试集确认。** 目前唯一候选是 affine-base / centered 残差前缀共享编码。必须包含仓库 prior-art 文档要求的 CSE / 共享前缀 / first_analog / 逐消费者 DCGS 对照，以及至少验证集上的精度与完整操作数 Pareto。若验证集无优势，不要把该方法当作 CVPR 贡献来写。
4. **真实成本，而不是只报 5×。** 至少：完整操作数分项（含门控、scatter、BN、head、访存代理）；稠密实现的墙钟；若主张高效，必须有减少**已执行工作**的实现（稀疏 / 缓存）及对照。没有实现就不要把效率写进贡献列表。5× 不应再作为必须达成的宣传目标。
5. **视觉说服力的最低加项（至少做一项，否则建议改投 ML 会议而非 CVPR/ICCV）：** 把同一协议接到一个真正的视觉图骨干（如 ViG 类）或一个事件视觉数据集，并达到该设定下可比较的精度；或在动态门控已有结果上把“哪些仍是模拟计算”画清楚，并做到审稿人认可的全图转换。仅超级像素两层 GCN 不够。
6. **误差与消融：** \(T=1/2\) 的大缺口要按层分解；门扰动界若仍使用，需给出与实测误差的松紧图；消融必须能分开宽度、\(T\)、读出、编码位置。
7. **可复现与政策：** 新稿数字与公开证据哈希一致；预先登记协议并披露测试暴露史；包含 LLM Usage Statement、审稿行号、2027（或目标会议当年）官方模板；引用全部经初级来源核对。

没有第 3 和第 4 项，很难称为方法贡献；没有第 2 项，可行性叙述也过不了审；没有第 5 项，CV 场地的 fit 仍然弱。
