|---|---:|---:|---:|
| MNIST · 四层 width-146 固定残差 GCN | 91.02±0.27% | 91.05±0.26% | 91.02±0.26% |
| CIFAR10 · 同上固定 GCN | 54.94±0.07% | 54.92±0.08% | 54.97±0.05% |
| CIFAR10 · 四层 width-70 GatedGCN | 68.77±0.41% | 68.75±0.33% | 68.76±0.39% |

更细的固定 GCN 端点（同一份三种子汇总）：

- MNIST T1/T2 仍有明显缺口：T1 均值 71.43±2.80%，T2 为 90.16±0.49%；T4/T8 与教师的类别一致率约 99.64–99.98%。
- CIFAR10 固定 GCN：T1 46.81±1.22%，T2 54.06±0.24%；T4/T8 一致率约 99.28–99.89%。

GatedGCN 只在 CIFAR10 上有三种子完整测试。教师–转换差距在 ±0.10 个百分点以内，测试集 T4/T8 与教师的一致率均值分别为 99.55±0.16% 和 99.90±0.03%。`gated-result-to-claim-v1.md` 把这正确地收成**窄范围可行性**：在这些冻结教师、该适配协议、T≤8 下可以保住教师精度；不支持“新的高效、算子无关方法、适合 CVPR 投稿”这类更宽主张。

与已发表的 Benchmarking GNNs 公开成绩对比（[JMLR 2022 论文](https://www.jmlr.org/papers/volume24/22-0567/22-0567.pdf)，排行见[项目 leaderboard](https://github.com/graphdeeplearning/benchmarking-gnns/blob/master-may2022/docs/07_leaderboards.md)）：GCN 在 MNIST / CIFAR10 上为 90.705±0.218% / 55.710±0.381%，GatedGCN 在 CIFAR10 上为 67.312±0.311%。仓库教师与这些数量级一致（CIFAR10 GatedGCN 68.77% 甚至略高），说明**强教师修复是成功的**，不再是历史稿里 MNIST 34.02%、CIFAR10 27.27% 那种过弱教师。缺口是：公开 GatedGCN 在 MNIST 上是 97.340±0.143%，仓库没有对应的 MNIST GatedGCN 教师与转换端点。

这些数字是完整数据、完整图下的**保真可行性**，不是新算法胜过最强忠实基线、不是 SOTA、也不是节能 5×。仓库反复强调两点，审阅同意：

1. 转换用的是钉死的 DCGS `MTH_diff` 差分单元（作者仓库 commit `5e0e4c73…`）的**项目图适配**，配的是完整训练集直方图校准，**不是**作者完整 converter / 阈值迭代的原样复现（见 `docs/METHODS.md`、`dcgs-threshold-procedure-source-note-v1.md`）。
2. 事件是带符号、多幅度的分级事件（文档写明八档），不是二进制 IF 脉冲；GatedGCN 路径每个 tick 仍在重算稠密的模拟门控、归一化与归约。

测试集在历史开发中已经暴露，三种子共享同一批样本，均值±SD 只是描述统计，不能当成独立盲测或显著性结论。

### 1.3 理论与候选新方法：有推导，尚未成为“已验收方法”

**固定线性图算子上的误差恒等式。** 对固定非负归一化邻接 \(A\) 和线性图读出 \(R\)，在同一读出与偏置约定下，\(\hat B-B=RA((\hat H-H)W_2)\) 是线性代数恒等式（`docs/METHODS.md`）。它能解释误差如何穿过图聚合与图级池化，但单独不能证明 \(\hat H\) 接近 \(H\)、分类正确、基线更强或成本更低。隐藏事件若为二进制脉冲，解码必须是 \(\hat H=\theta\cdot\sum(\mathrm{spike})/T\)；旧稿在 \(\theta\neq 1\) 时未乘 \(\theta\)，恒等残差可以近零却保不住所声称的教师关系。这是已经定位并修复的真实错误，不是文风问题。

**动态 GatedGCN 的困难。** 门、乘法、分母和归约都依赖当前状态，不能把固定线性 \(A\) 的恒等式直接宣称覆盖所有动态算子。仓库为此写了归一化门的扰动界（`stable-normalized-gate-bound-v1.md`）：把 \(\epsilon\) 分母项看成消息为 0 的 dummy 质量，用 log-sigmoid 的 Lipschitz 性与全变差，得到消息误差由输入消息扰动和消息范围 \(\times\tanh(\eta/2)\) 控制，从而避免小门值下 \(1/\epsilon\) 型估计爆炸。这是带假设的实数算术局部界，有固定种子的 20,000 随机例与 24 个边界例的 NumPy 检查；它**不是**浮点证书、分类保证、缓存命中率或端到端深度网络的误差证书。误差递推仍须计入 BN、残差和分类头。

**源码固定的差分编码适配。** 差分输入可写为 \(e_t=t(a_t-a_{t-1})\)，前缀解码为 \(\sum(e_t/t)\)。这是对 Huang 等人 DCGS 源单元的适配（见第 2 节）。仓库对 zero-latch、active tick、重置、偏置进入时点和读出做了独立检查。当前稠密混合实现的线性 MAC 是 `embedding + T * body`，在所报告的 \(E=8N\) 队列上，T4/T8 的稠密线性 MAC 大约是 ANN 的 4 倍 / 8 倍（`gated-differential-dense-cost-v1.md`）。低 T 保真在这里**不等于**稀疏执行或更低能耗；相对 ANN，这个实现算出来是更贵的。

**affine-base / shared-consumer 候选。** 这是目前唯一看起来像“本项目自己的方法”的主线。做法是把恒等残差状态写成 \(h_\ell=h_0+q_\ell\)、\(e_\ell=e_0+r_\ell\)，对非负 ReLU 残差增量的原始累计和做差分编码，并在同层的 A/B/D/E（节点）与 C（边）之间共享编码前缀；残差 skip 仍走原始 \(q,r\)，不能把解码后的量代回 skip；分类头保持同一模拟 MLP。三种模式（`generic` / `first_analog` / `centered`）× 两种事件尺度的 6 组完整 45k 训练集诊断已经跑完，并保存了共享阈值控制（`affine-six-profile-audit-v1.md`）。

审计给出的是**无标签的训练集教师类别一致率**，不是 ground-truth 准确率，也没有验证集 / 测试集外推。以 scale=1、T=4 为例：`generic` 一致率 0.99316，`first_analog` 0.99749，`centered` 0.99751，同时 `centered` 的前瞻投影 ADD 更低。协议把这记为 TRIGGER，只授权继续做预先约定的共享 \(\theta\) 控制，**不授权宣称新方法已成功**。仓库自己的结论应被遵守：这些是机制诊断，不是测试提升、效率或新颖性的验收。

### 1.4 早期图学习轨迹（Cora / CiteSeer / PubMed）

`research/early-graph-conversion/` 记录了两层 Kipf GCN 在 Planetoid 上的转换。`results/consolidated_results.json` 中，ANN 测试准确率为 Cora 0.8046、CiteSeer 0.7016、PubMed 0.7750；FTBC + 膜电位读出在 T=8 的均值分别为 0.8016、0.6872、0.7728（与审计文 `d1-experiment-audit.md` 中 0.8018 / 0.6902 / 0.7676 略有出入，可能来自不同次修复后的运行，引用时应以具体 JSON 为准）。该审计还写过 chameleon、squirrel 和 ogbn-arxiv 的扩展，以及直接训练的替代梯度对照；这些扩展的原始大结果**没有**进入当前精简包，只能当作审计叙述，不能当作本仓库可复核的主证据。

这段工作有真实的排错价值（`test.index` 错位、层间缩放、第二层应累计二进制脉冲等），但后来的视觉主线表明：同类组合在弱教师、不忠实基线、错误 \(\theta\) 解码和成本漏项下会被严重高估。早期“strong = ANN−1.5% @ T≤8”的门槛本身也偏低，不足以支撑高水平发表。应把早期轨迹当作已修复的方法学课堂，而不是博士论文的第一篇现成论文。

### 1.5 已经关掉的路线（负结果，应保留）

`docs/RESEARCH_LOG.md` 和总览中已记录、不应再包装成正面贡献的结果包括：

- learned-initialization：MNIST 三个种子都落后于 FTBC，CIFAR 优势小且符号不一致。
- stale CDE / controller 复用：在固定 \(\tau=0.01\) 下未取得有用的非零误差复用，现有算术下限不够 5×。
- branch-fanout 编码：即使在有利计价下，完整训练集事件量仍不满足旧的 5× 边界；`gated-dual-arithmetic-screen-v1.md` 在 T=1 就拒绝了这条投影缓存算术路径（候选已知项 / ANN ≈ 0.2536，目标是 ≤0.2）。
- 若干被命名为 QCFS / FTBC / TPP 的旧比较只是近似实现，且读出不同，不能冒充原作者算法。

这些负结果对博士论文是有用的：它们界定了“什么不能再声称”，也给审稿人展示问题被认真对待过。

## 2. 在文献中的位置（已核验）

把贡献说准确，比把贡献说大更重要。下面只列本次检索或仓库 prior-art 文档给出初级来源的工作。

**直接相关、必须正面比较的转换工作。**

- **DCGS**（Huang 等，ICML 2025）：[PMLR 正式页面](https://proceedings.mlr.press/v267/huang25i.html)，[arXiv:2503.00301](https://arxiv.org/abs/2503.00301)，[作者代码](https://github.com/h-z-h-cell/ANN-to-SNN-DCGS)。训练免费的差分编码 + 阈值迭代，实验在 CNN 与 Transformer 上。仓库主线的源单元就是这里的 `MTH_diff`。因此，“在图上保住教师精度”首先是**对已有源单元的适配与可行性**，不能写成“我们提出了差分编码”。作者路径与 generic 路径的阈值规则不同，项目用直方图校准并改到图算子——这是需要说清的差异，但差异本身还不是一篇方法论文的全部贡献。
- **One-Spike SNN**（Hwang & Kung，IEEE TETC 2025）：[DOI 10.1109/TETC.2024.3386893](https://doi.org/10.1109/TETC.2024.3386893)，[arXiv:2403.08786](https://arxiv.org/abs/2403.08786)。用单脉冲相位编码把 CNN 和 **Text GCN** 转成 SNN：在 20NG、R52、R8、Ohsumed、MR 上平均精度损失 0.90%（T=16），并报告相对 ANN 4.53–11.11× 的能量效率（同样是理论估计）。作者明确写过“此前没有 GCN 转换结果”。历史稿里“尚无已发表的 GCN 转换”这类句子已经不成立，引用审计也指出了这一点（`paper/reference-audit/reference-truth-audit-v6.md`）。任何新稿必须把 One-Spike 放进相关工作，并在**同一教师、同一图任务**上做忠实对比。

**评测与直接训练的脉冲 GNN。**

- **SGNNBench**（[arXiv:2509.21342](https://arxiv.org/abs/2509.21342)，检索时可见 NeurIPS 2026 poster 条目）：在 18 个数据集上评估 9 种 SGNN，重点是有效性、理论能耗与结构组件。从摘要与实验设置看，它是对**已有脉冲图网络**（多为直接训练）的基准，不是 ANN-to-SNN 转换基准。历史稿“SGNNBench 无转换方法”的表述仍须按全文逐句核对后再用，不能直接当事实写进新稿。
- 直接训练的脉冲 GNN 已是独立文献族（如动态图上的 Dy-SIGN 等）。博士课题若只做转换、完全不在同一教师 / 同一划分上对照替代梯度 SGNN，审稿人几乎一定会问。

**教师质量的参照，不是转换方法。**

- **Benchmarking GNNs**（Dwivedi 等，JMLR 2022）：上面第 1.2 节的公开成绩。仓库把教师拉到与这篇基准同一量级，是后面一切主张的前提。

**经典 ANN-to-SNN 基线（必须忠实实现，不能再近似）。**

- **QCFS**（Bu 等，ICLR 2022）：量化 clip–floor–shift 激活，[ICLR 页面](https://iclr.cc/virtual/2022/poster/5899)，[作者代码](https://github.com/putshua/ANN_SNN_QCFS)。
- **FTBC**（Wu 等，ECCV 2024）：前向时间偏置校正，[arXiv:2403.18388](https://arxiv.org/abs/2403.18388)，[Springer 章节](https://link.springer.com/chapter/10.1007/978-3-031-72890-7_10)。

**差分 / 增量计算的先例（限制“编码方式”本身的新颖性）。**

仓库 `affine-incremental-prior-art-v1.md` 已经做了有节制的初级来源筛查，结论审阅同意：差分传播、线性算子与增量交换、共享消息缓存、偏置 / 基项搬移都不是新的。该文档列出的 Sigma-Delta Quantized Networks（O’Connor & Welling，ICLR 2017，[OpenReview](https://openreview.net/pdf?id=HkNRsU5ge)）、DeltaCNN（Parger 等，CVPR 2022，[CVF](https://openaccess.thecvf.com/content/CVPR2022/html/Parger_DeltaCNN_End-to-End_CNN_Inference_of_Sparse_Frame_Differences_in_Videos_CVPR_2022_paper.html)）、DynaGraph 与 Ingress，足够用来拒绝“首次差分图转换 / 首次共享消费者 / 首次增量 GNN”这类宽口径。仍可能成立、因而值得作为论文 C 去证明的，只是**这个具体组合**：在固定图、有界转换时域上，对恒等残差 GatedGCN 做非负残差前缀编码、共享多投影消费者，并正确处理动态归一化门——以及它是否带来可测量的精度–成本好处。

## 3. 具体弱点与缺口

### 3.1 理论

现有恒等式和门界是清楚的、有检查的，但距离一篇独立理论论文还差一层。

- 固定 \(A,R\) 的误差恒等式在数学上几乎是线性性的直接推论。它的价值在于：澄清图级池化不额外引入误差、排除 float32 积累造成的假残差、并抓住错误解码（未乘 \(\theta\)）这种会让“恒等式成立但教师保真失败”的陷阱。若论文只停在“我们验证了机器精度的恒等”，贡献偏薄。
- 归一化门界是局部的、针对单次聚合的，尚未与 BN、残差累加、多层递推和分类间隔连成可检验的端到端误差预算。仓库自己也写了：不得把局部门界当成最终分类保证。下一步应给出界的松紧测量（界 vs 实测层误差、logit MSE），以及它在何种门锐度 / 度数下会变得无用。
- 历史稿把 \(\beta^\star=\theta/(2T)\) 在确定性两阶段排程下“双重校正”当作机制贡献。这个观察可以保留，但要小心：若“两阶段”本身是离线先定总 count 再排程（`RESEARCH_LOG.md` 已把 offline 与因果 IF 区分开），则它与在线 IF 的偏置修正不是同一对象；相同 T 得到相同 count/logits 时，名字或排程不能构成独立准确率优势。
- “算子无关”（operator-agnostic）目前没有证据。动态门已经迫使实现走出固定线性恒等式。这个词在被实验覆盖之前不应出现在标题或贡献列表里。

### 3.2 转换误差分析

- T4/T8 的保真很强，但 T1 缺口很大（MNIST 固定 GCN 约 −20 pp，CIFAR 固定 GCN 约 −8 pp）。这恰恰是低延迟文献关心的区域。应做成按层、按位点、按图大小的误差分解：重建误差、门logit误差、归一化分母、残差累计、BN 缩放、分类间隔被侵蚀的量。现在这些分解还不构成论文主表。
- 训练集 affine 诊断的一致率很高，但一致率不是准确率，更不是测试集外推。缺少“同一冻结协议下，候选方法相对 DCGS 式逐消费者编码、共享 generic 前缀、first_analog 的成对比较”。
- 分级多幅度事件与二进制脉冲在能量模型、神经形态可部署性和“SNN”一词的惯例上都不相同。正文必须分开报告，不能用“脉冲”一词把八档有符号事件说成标准 IF。

### 3.3 基线

这是当前离可发表最远、又最好补的缺口之一。

- 历史稿表 `tab_baselines.tex` 里，naive / QCFS / FTBC / TPP / parallel 在 T=4/8 上接近随机（约 10–18%），“Ours”则是 62.60 / 65.79（MNIST）和 32.76 / 34.10（CIFAR10）。结合 34% / 27% 的弱教师、以及日志中“基线只是近似且读出不同”的结论，这些对比**不能再引用**。把不忠实的弱基线打到随机附近，再宣称大幅领先，会被审稿人直接否定。
- 已核验的强教师端点，几乎没有与**原作者代码**对齐的 QCFS、FTBC、官方 DCGS converter、One-Spike 的对照。learned-init 对 FTBC 已是负结果，说明“最强参照只有 FTBC”也不成立。
- 没有在同一超级像素教师上对照直接训练的脉冲 GNN。
- GatedGCN 的稠密混合把门控留在模拟域，和“全脉冲转换”不是同一设置；对照时必须把“哪些部分仍是 ANN 算术”写成明确的方法边界。

### 3.4 数据集与基准覆盖

- 视觉主线实质是两个数据集、两类算子（固定 GCN 与 CIFAR10 上的 GatedGCN）。没有 MNIST GatedGCN，没有 GAT / GIN / GraphSAGE / PNA，没有 PATTERN、CLUSTER、ZINC 等同系列基准，也没有 OGB 作为视觉主线的已核验证据。
- SuperPixel CIFAR10 即使教师到了约 69%，绝对精度仍远低于像素 CNN。用它讲“视觉图转换”是合理的测试床，但不足以单独支撑“图结构视觉的普遍方法”。若目标会议是 CVPR，审稿人会要求更大的视觉图模型（例如 ViG 类）或事件相机 / 动态视觉图；那是后一阶段的工作，且应与果蝇课题分开。
- 早期 Planetoid 结果与视觉主线的教师、深度、读出、校准协议并不对齐，不能在同一张主表里混报。

### 3.5 能量与延迟

这是当前主张里最容易被打回的部分。

- 历史稿的 5×（45 nm，两种约定，20 个种子无例外）建立在过弱教师、窄网络、不完整成本账和有问题的 holdout 之上，**已经不能用**。
- 现有稠密实现在 T>1 时线性 MAC 明显高于 ANN（约 T 倍主体计算）。`gated-result-to-claim-v1.md` 写得很明确：当前公式已经显示更多稠密线性 MAC。
- branch-fanout 缓存路径在有利假设下 T1 就未过 5×。affine-base 的前瞻投影 ADD 有所下降，但仍只是“一个算术分量”，不是端到端能量、墙钟或芯片测量；完整成本屏在暂停时仍为 pending（`PAUSE_SNAPSHOT_20261113.md`）。
- 成本账必须继续分开：首层模拟、base 构建、投影、编解码、\(1/t\)、分级 bank、sigmoid、乘积、归一化、scatter、残差、BN、head、pool、存储与搬运。仓库日志已指出：edge BN 的 \(z\) 同时供 sigmoid，不能折完 CDE 后宣称免费。这个清单应变成论文里的标准表，而不是附录里的口头注意。
- Horowitz ISSCC 2014 的 45 nm 表（[DOI](https://doi.org/10.1109/ISSCC.2014.6757323)）只能当算术惯例，且 32-bit MAC/AC 比值只有约 5.11，要宣称 5× 几乎必须让 SNN 的操作数低于 ANN 的 MAC。没有稀疏内核、没有墙钟、没有访存，5× 不宜再作为“必须达成”的宣传目标；它可以留作内部筛选阈值，但论文应改报**完整、可复核的 Pareto**。DeltaCNN 已经警告：稀疏 FLOP 不会自动变成加速。

### 3.6 可复现性

优点：证据 ZIP 有逐文件 SHA、restore 拒绝覆盖不同内容、运行元数据记录了源码哈希与校准哈希、`environment-executed.yml` 保留了原 `dyg-cold` 环境（Python 3.13、Torch 2.11+cu128、PyG 2.8、RTX 3060 12GB）。

缺口：

- 脚本中仍有原 Windows 布局 `C:/code/phd-snn/…` 的绝对路径（至少出现在 `docs/REPRODUCE.md` 的说明和 `stable-normalized-gate-bound-v1.md` 的链接）。跨机器必须重定位，且不能回改旧实验结果。
- 精简包有意不收录原始大对话、巨型 snapshot 和失败实验的大数组。这可以理解，但文档中引用的若干文件在本仓库里并不存在，例如 `correction-ledger.md`、`historical-track-repair-plan-v2.md`、`baseline-fidelity-audit-v1.md`、`twe-primary-audit-v1.md`、`centered-residual-prior-art-v1.md`、`reference-truth-audit-v5.md`、`gated_dual_code_v1.py`。外部读者无法顺着引用把证据链走完。
- 没有 SPDX / 开源许可证，只有 `RIGHTS.md` 的权利声明。公开代码若希望被人复现或对照，需要单独澄清代码许可；这不要求现在把历史稿也一并授权。
- 没有一条“从空环境到复现表 1”的端到端命令。代码是按实验脚本堆积的（`*_v1` 到 `*_v4`），依赖钉死的外部 DCGS checkout。环境导出是完整 Anaconda 列表，复现成本偏高。
- 官方测试集已暴露：以后的论文必须写明，并在任何新方法上**先冻结协议再跑测试**，最好另留一个此前完全未用于调参的确认划分，或报告预先登记的协议。

### 3.7 代码质量

这是研究代码的诚实快照，不是库。`check_*.py` 与审计脚本的存在是加分项；版本后缀和协议–结果成对保存也有利于追溯。作为博士交付，还缺：

## 4. 按优先级排列的改进建议

以下顺序按“对可发表性的影响 / 工作量”排列。前三项是恢复研究后应立刻做的事。

**P0. 主张纪律（立即，几乎零成本）。**

- 停止使用历史稿主表、5×、SOTA、“首次 GCN 转换”、“算子无关”、“高效混合”等说法。
- 对外只陈述已核验的保真可行性，并带上：完整测试已暴露、分级事件、稠密门控仍在、非官方 DCGS 全流程复现。
- 新稿文献从实际主张出发重新选择，跑完真实性核查；不要为凑条目或年份窗口加未读文献。候选修正已在 `references-corrections-v6.bib`。

**P1. 把 affine-base 做成可验收的方法实验（最高科学优先级）。**

恢复后的第一个实验包应预先登记，并且输入、教师、校准、种子和划分都冻结：

1. 在已保存的 6+4 条训练诊断之外，用同一冻结教师跑**完整验证集**，协议与工作点只在验证集上选择。
2. 协议冻结后再跑完整测试，明确“历史暴露”限制，不再用测试做选择。
3. 必须包含仓库 prior-art 文档已经要求的忠实对照：精确 ANN、普通逐消费者 DCGS 式编码、共享 generic 前缀、first_analog、centered affine-base，以及一个 CSE / 缓存对照，避免把“少算了重复投影”写成新机制。
4. 至少再加两个教师种子，并尽量补 MNIST GatedGCN。
5. 同步给出完整成本账；若仍没有稀疏实现，只报操作数与墙钟（稠密），不要报 5× 能量优势。
6. 共享 \(\theta\) 控制已经 TRIGGER，应先完成并独立审计，再决定是否扩大。

没有这组实验，论文 C 不存在；有了负结果，也可以诚实写成方法边界，比勉强投稿好。

**P2. 在现有强教师上补忠实基线（性价比最高的“让保真结果可发表”之路）。**

对已经冻结的 9 个教师（或至少每种设置一个主种子），用原作者代码或严格对照实现跑：官方 DCGS 转换流程（若能合理接到图算子则接，不能则写明失败边界）、One-Spike、QCFS、FTBC，以及一个替代梯度直接训练的脉冲 GNN。报告精度、与教师的一致率、logit MSE、事件数、完整操作数。这会把第 1.2 节的可行性结果从“内部适配端点”变成可以答辩的经验结论，并很可能揭示：在 T=4/8，差分源单元已经把保真问题基本解决，真正开放的问题是成本与更难的算子。

**P3. 做一个真正减少已执行工作的实现。**

没有事件库 / 稀疏或增量内核，效率论文过不了关。实现应对照 DeltaCNN 的教训：以墙钟、访存和端到端操作数为准，而不是以非零事件数为准。若硬件（Loihi、SpiNNaker、或至少 GPU 稀疏核）暂不可得，先把软件端的真实加速测出来；测不出来就不要把效率当贡献轴。

**P4. 扩大算子与数据，但不要摊薄主线。**

在 P1–P2 的协议稳定后，再加至少一种注意力或动态邻域算子（如 GAT）作为**失败边界或成功推广**，以及 Benchmarking GNNs 里的另一个任务（如 PATTERN）。目的是支撑“图算子分类”的科学问题，不是堆数据集。MNIST GatedGCN（公开约 97.3%）应优先于再加一个弱 GCN。

**P5. 把理论界做成可证伪的经验对象。**

用同一批 GatedGCN 前向，画出局部门界、组成后的深度递推上界、与实测误差的比值；报告何时界是紧的、何时无用。这是论文 A 的核心图，也能给论文 C 的稳定性主张提供非空内容。

**P6. 工程与复现整理（可与实验并行）。**

相对路径、精简 `environment.yml`、一条复现说明书、对缺失被引文件的处理（补进附录包或删除悬空引用）、代码许可、把评测路径做成带回归测试的模块。不必为此单独发软件论文，但这是审稿人愿意复现的前提。

**P7. 完全重写稿件，再接受独立评审。**

新稿只使用第 1 节及 P1–P2 的新证据。不要在同一套流水线里既改稿又打目标分数。独立评审若仍在 6 分附近，应用新实验而不是用写作去抬。

## 5. 博士论文架构：四条相互独立的贡献轴

不建议把“GNN 转 SNN”做成一篇包打一切的大论文，更不建议把历史稿改一改当第一章。下面四条轴在问题、方法和评价标准上可以分开辩护；若某条证据不足，可以降级为论文中的一节或附录，而不拖垮其他轴。果蝇连接组课题保持独立，最多在总论的“应用展望”里提及。

建议的论文标题是工作标题，定稿前按实际证据收缩，不要先写满再找数。

### 论文 A. 图算子上的转换误差：恒等式、门界与失效条件

- **独立贡献轴：** 理论——哪些图算子上转换误差可以精确因子分解，误差如何穿过归一化动态门，以及这些结论在何处失效。
- **研究问题：** (i) 线性固定邻接与线性读出下，图级转换误差是否严格等于隐藏表示误差的线性像？解码、gauge 与偏置约定如何改变可声称的关系？(ii) 对目标节点归一化的 sigmoid 门，能否给出不在小门处爆炸的扰动界？该界在多层残差 + BN 后有多紧？(iii) 注意力、动态 \(k\)-NN、非线性池化分别破坏了哪些步骤？
- **方法：** 在现有恒等式与门界上补全假设、符号和组合定理；用已保存的教师前向测量界与误差的比值；构造最小反例展示失效边界。不把“提出新编码器”混进这篇。
- **实验：** 以测量和反例为主，不依赖新方法打赢基线。需要覆盖固定 GCN 与 GatedGCN，并至少有一个已知破坏因子分解的算子。
- **目标期刊 / 会议：** ICLR、NeurIPS，或 IEEE TNNLS / *Neural Networks*（理论+测量更适合长文时）。若定理止于线性恒等、门界又较松，更稳妥的是作为论文 C 的理论节，而不是单独投稿。
- **大致时间：** 恢复后 3–6 个月可写出预印本（大量推导已存在）；是否独立成篇，看端到端界是否真有预测力。
- **与其他轴的边界：** 不报告 affine-base 的测试准确率作为本篇贡献；可用其误差轨迹当测量，但贡献句只谈界与失效。

### 论文 B. 强教师、忠实基线下的视觉图转换：可行性、失败模式与协议

- **独立贡献轴：** 经验刻画与评测协议——在公开架构、完整数据、忠实基线下，训练免费转换在图视觉任务上到底能做什么、在何处失败。
- **研究问题：** (i) 当教师已达到 Benchmarking GNNs 量级时，现有转换族（官方 DCGS、One-Spike、QCFS、FTBC、朴素速率、项目图适配）在 T∈{1,2,4,8} 上的保真与成本各是什么？(ii) 固定线性算子与动态门控算子的差距有多少来自门的状态依赖，有多少来自实现仍把控制器留在模拟域？(iii) 如何定义一套不再把测试集当调参器、不再用近似基线的报告协议？
- **方法：** 冻结教师与校准；原作者代码优先；预先登记协议；完整验证 / 测试；操作数与事件分项记账；明确模拟部分与事件部分。
- **实验：** 至少 SuperPixel MNIST 与 CIFAR10；算子至少固定 GCN 与 GatedGCN，最好加 GAT 或 GIN；三种子；与直接训练 SGNN 的对照作为技术族控制。第 1.2 节的端点是起点，不是终点。
- **目标期刊 / 会议：** 若能抽出清晰的算子层面结论，可投 ICLR / NeurIPS；若主要是严谨基准，宜投 NeurIPS Datasets & Benchmarks，或作为 TNNLS 长文。不要为了“像 CVPR”而在证据不足时强调通用视觉。
- **大致时间：** 与 P2 同步，4–8 个月（含忠实复现的工程时间）。
- **与其他轴的边界：** 本篇比较的是**已有方法**（含项目适配作为“DCGS 图适配”这一栏，而不是“Ours 大幅领先”）。新编码的胜利留给论文 C。若 C 的方法最终没有优势，B 仍然可以独立成立。
- **警告：** 不要和论文 D 拆成两篇内容重复的文章。若基准深度不够，把协议并进 B，取消单独的 D。

### 论文 C. 面向恒等残差图网络的残差前缀编码与共享消费者（主方法文）

- **独立贡献轴：** 新的数据流——把状态写成仿射基 + 非负残差，残差前缀只编码一次，并被同层多个投影共享；以及该数据流在保真和**已执行工作**上是否优于最强忠实对照。
- **研究问题：** (i) 该重写在实数算术下与教师的关系是什么，近似源单元插入后误差如何走？(ii) 在共享阈值、共享校准、CSE 对照齐全时，centered 模式是否仍有机制上的好处（事件更少、投影 ADD 更少、验证精度不掉）？(iii) 在真实稀疏 / 缓存实现里，墙钟或完整算术成本能否优于 ANN 与 DCGS 式稠密适配？若不能，边界在哪里？
- **方法：** 现有推导包 v2 + 必须补上的稀疏实现；对照组见 P1；新颖性表述严格限制在“具体组合”，并引用 Sigma-Delta、DeltaCNN、DCGS、DynaGraph。
- **实验：** CIFAR10 GatedGCN 为主（这是动态门真正出现的地方），MNIST GatedGCN 与固定 GCN 为推广；验证选点、测试确认；成本与精度的 Pareto；失败案例（高事件密度、窄间隔、尖门）。
- **目标期刊 / 会议：** ICML、ICLR、NeurIPS；若实现与视觉图叙事都扎实，可考虑 CVPR，但审稿会更追问规模与真实效率。没有稀疏实现或没有胜过忠实对照时，不要投成“高效 SNN 方法”。
- **大致时间：** 这是关键路径，恢复后 8–12 个月（含实现与多次验收）。暂停前的训练诊断可以缩短校准阶段，但不能跳过验证 / 测试。
- **与其他轴的边界：** 不把论文 A 的一般定理或论文 B 的基准本身算作本篇的新方法贡献。5× 不是发表条件；一个诚实、有对照、有实现的 Pareto 才是。

### 论文 D（可选）. GNN→SNN 转换的公开评测包

- **独立贡献轴：** 软件与协议资产——可安装的忠实基线包装、标准划分、成本表、断言检查（\(\theta\)、gauge、标签隔离、哈希）。
- **仅当** 论文 B 没有把这些说完、并且你愿意维护一个别人能跑的仓库时才独立成篇。目标：NeurIPS D&B。时间放在 B、C 投稿之后（约第 12–18 个月），避免把工程包装写成第四个“方法贡献”。

### 论文结构在学位论文中的摆放（建议）

1. 绪论：问题、文献（DCGS / One-Spike / 直接训练 SGNN）、历史弯路（弱教师、不忠实基线）作为动机，不作为成果。
2. 背景：图算子、转换、能量模型的假设与限制。
3. 第 3 章 = 论文 A。
4. 第 4 章 = 论文 B。
5. 第 5 章 = 论文 C（学位论文的方法核心）。
6. 结论与展望：神经形态实测、更大视觉图；**果蝇课题另章或另册**，不在本章报告主结果。

粗时间线（从恢复研究起，按全日博士节奏的示意，不是承诺）：0–3 个月完成 P1 验证集与忠实对照原型，并收紧 A 的界；3–8 个月完成 C 的实现与第一稿、B 的基线表；8–14 个月投稿与返修；14–24 个月定稿学位论文。若 P1 给出明确负结果（新编码无验证优势、成本也不降），应尽早收缩 C，把博士主成果转到 A+B 的“算子理论 + 严谨刻画”，而不是继续加模块。

## 6. 风险，以及怎样经得起强评审

**审稿人最可能打回来的句子，以及应对。**

| 风险 | 为何真实存在 | 应对 |
|---|---|---|
| “这就是把 DCGS 接到了 GNN 上” | 源单元确实是钉死的 `MTH_diff`；T4/T8 保真很可能主要来自该单元 | 相关工作把 DCGS 放在第一位；主表把“项目适配”与“官方 converter”分开；新贡献只谈被实验分开的部分（残差坐标、共享消费者、门的处理、成本） |
| “One-Spike 已经做了 GCN 转换” | 已发表，且含能量数字 | 比较任务差异（Text GCN vs 视觉超级像素，T=16 相位编码 vs 低 T 差分），并做同设定实验，不写“首次” |
| “这些不是脉冲，是分级事件” | 文档已承认八档有符号事件 | 术语全程分开；若投 SNN 场地，讨论与二进制实现的差距，或补二进制对照 |
| “所谓节能是 45 nm 纸面账，实现还更贵” | 稠密 MAC 已是 ANN 的约 T 倍 | 效率主张延后到有实现之后；当前只报保真与完整操作数 |
| “测试集不是盲的” | 仓库自己标注了 prior exposure | 新方法预先登记；披露暴露史；能另设确认集更好 |
| “基线不忠实” | 历史稿已经发生过 | 只用官方代码或有逐项对照的复现；旧表作废 |
| “教师太弱，能量来自把网络削窄” | 历史稿确实如此 | 新稿教师对齐公开基准；能量与精度必须画在同一 Pareto 上 |
| “两篇论文贡献分不开” | 同一项目里适配、理论和新编码很容易写重 | 严格遵守上面四条轴的边界；不够独立就合并，不要拆 |

**评审过程上的建议。** 仓库历史里出现过“当时版本的高评审分 / stage pass / energy_ok”，随后被证据修正推翻。同一代理、同一流水线、带目标分的评审不能当作独立同行评议。对外送审应在证据锁定之后，由未参与改稿的人按公开标准阅读全文，并且**不**把目标分数告知评审。若分数仍不高，回去补实验。

**开题与答辩时建议主动承认的边界。** 主线目前是超级像素图分类，不是 ImageNet 级视觉、不是芯片实测、不是对 DCGS 差分编码的替代；已核验的最强数字是低 T 保真，不是方法胜利。这种承认不会削弱课题，反而说明你能把“已做到”和“还想做”分开——这正是当前仓库已经形成、应当保持的风格。

## 一句话判断

当前仓库已经把 **“强视觉图教师上，DCGS 差分单元的图适配可以在 T=4/8 近乎保住精度”** 做成可复核的事实，并把理论候选、负结果和主张边界整理得相当清楚；它还**没有**做成一篇可以投稿的新方法论文，也还没有经得起强评审的能量或新颖性证据。博士大课题是成立的，但主线应从“再写一篇转换通稿”转向三条可分开辩护的轴：图算子上的误差理论、忠实基线下的经验刻画，以及（仅当验证集与真实成本过关时）残差前缀共享编码这一具体数据流。历史稿应封存为过程文件，不以任何形式投稿。
