# 研究总览与暂停快照

## 归档目的

这不是一个宣称研究已经成功、已经达到SOTA或者已经可投稿的发布。它是应项目所有者要求，把 GNN→SNN 这个大方向的研究成果、历史、原始证据和未解决问题整理成可持续接手的公开档案。研究目标于2026-11-13由用户明确暂停；公开整理和上传不代表恢复训练或继续自动研究。新实验需要用户另行恢复。

主线是视觉图网络的 ANN-to-SNN 转换。早期从 Cora/CiteSeer/PubMed 的图学习转换起步，后来研究聚合内时序错位、误差恒等式、输出膜电位／电流读出，并转向 SuperPixel MNIST/CIFAR10。WorkBuddy 还探索过相关视觉时空图／果蝇连接组／光流分支。后续接手的主要任务是修复弱teacher与非全量实验问题：采用公开架构的完整数据强教师，保留一个独立的旧两层小规模分析，并建立匹配基线、机制实验和完整成本核算。

## 当前事实

- 完整数据的四层width146 GCN教师，MNIST完整10k测试三种子准确率90.94/91.32/90.81%，平均91.02%。这是全量主线，不是旧两层窄模型。
- CIFAR10固定GCN完整测试教师54.87/54.94/55.01%；更强的四层width70 GatedGCN教师69.20/68.39/68.72%，平均68.77%。它是公开架构的PyG适配，不冒充原作者DGL训练过程的逐项复现。
- 固定GCN的项目MTH源单元图适配在T4/T8近乎保持教师精度，两个数据集各有三教师种子的完整测试预测。GatedGCN的既有差分适配也在三个教师上保持T4/T8保真，但仍包含模拟门控和稠密计算。
- 这些是基线适配／可行性结果，不是我们已经战胜最强基线或建立新颖性的证明。旧learned-initialization候选在MNIST三种子都落后FTBC；CIFAR优势小且符号不一致，不能继续以FTBC作为唯一最强参照。
- 新的affine-base/shared-consumer候选完成了三模式×两尺度的6个完整45k训练集诊断，进一步完成了4个共享阈值控制的原始结果保存。训练集agreement不是ground-truth accuracy；未做新候选验证／测试外推验收。
- 旧两层轨已修复theta解码、gauge与首次更新前mask问题，完成MNIST2k/3k、seed0、完整5k验证／10k测试；其余数据集／种子尚未补完。
- 理论／代码审查、负结果与引用修复均保留。没有通过完整成本5×、稳定新方法优势、新颖性或当前成稿独立CCFA≥7/10的最终验收。

## 不应混淆的状态
