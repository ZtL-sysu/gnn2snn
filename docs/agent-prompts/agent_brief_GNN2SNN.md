### 1.4 已知短板（你这一轮要解决的就是这些）

1. **CiteSeer 落后 3.4 pp**（69.07 vs SpikingGCN 72.5），且「对方 SNN 比我们的 ANN 还高」，高度疑似协议差异 → **未查清**。
2. **只做了 2 层**：深度 >2 的误差累积没有理论，导致无法用 GCNII/DAGNN 这类强骨干。
3. **没有任何能耗主张**：脉冲数是直训的 2 倍（等时延）、多 17–83%（等精度）。
4. **基线全是自己实现的**「同架构不同训练范式」，没有复现任何已发表方法。
5. **ANN 本身偏弱**：Cora 80.60（发表值约 81.5）、PubMed 77.57（约 79.0）、arxiv 65.95（标准 GCN 约 71–72）。

## 2. 论文定位与断言阶梯（claim ladder）

**不要试图一次讲四件事。** 按下面三级阶梯构建，每级都有明确的证据要求和升降级判据。

### L1 — 必得（没有它就没有论文）
> **图上第一个 ANN→SNN 转换框架，且转换误差有精确代数结构。**

- 证据：恒等式、闭式偏置、膜电位恒等式、时延定理、现有全部实验表。
- 已基本完备。**不可丢**。

### L2 — 差异化（拿分会靠它）
> **在低时延区（T ≤ 4）不被任何直训方法支配：等精度下 T 减半，训练成本 1/35。**

- 需要：统一协议下复现 ≥3 个已发表直训方法（SpikeNet / SiGNN / SpikingGCN），产出 `accuracy–T` 与 `accuracy–脉冲数` 两条 Pareto 曲线（WP2）。
- 判据：在 T ≤ 4 区间，转换点不在任何直训点的支配域内。

### L3 — 拉伸（高风险高回报，允许失败）
> **转换可以超过它自己的上限（ANN）**，或 **深度推广到多层 + 强骨干**。

- 需要：E2 多视图集成（WP5）、多层误差追踪（WP3）。
- 判据：E2 在 ≥2/3 图上超过各自 ANN（幅度不限，但必须过噪声底 ×2）；或 WP3 的界在 3–4 层上 0 反例。

### 禁止的断言
- ❌ 「我们省电」——除非 WP4 达标。
- ❌ 「我们精度 SOTA」——除非 Gate 3 通过。
- ❌ 「首个图脉冲网络」——只能说「据我们所知，首个图中的转换方法」。
- ❌ 任何「超过 ICML'25」的表述——任务不同，只能并排说 gap。

## 3. 必须遵守的实验协议（WP0，第一周做完，之后冻结）

写进 `experiments/protocol.md`，之后所有实验引用它，**不许中途偷改**。

1. **划分**：Planetoid 公开划分（Cora 140/500/1000，CiteSeer 120/500/1000，PubMed 60/500/1000）。**禁止随机划分**，若要跑随机划分，单列附录并标注。
2. **种子**：≥ 7 个（0–6）；报告 mean ± std；配对 bootstrap 95% 区间。
3. **超参预算对等**：转换臂与直训臂使用**相同的搜索预算**（同一组 lr/hidden/dropout 网格、同样的早停规则）。
4. **噪声底规则**：同一份代码换设备重跑，均值最大位移记为 `noise_floor`（当前 0.4 pp @ T≥8）。**任何「提升」必须 > 2 × noise_floor 才算数**，否则一律记为「打平」。
5. **T 网格固定**：`{2, 4, 6, 8, 16, 32}`；所有方法跑同一网格。
6. **必须记录的指标**：accuracy、与 ANN 的 gap、每节点脉冲数、估算 SOPs（`T × 边数 × 隐藏维`）、训练墙钟时间、**「为覆盖该 T 网格所需的重训次数」**（直训 = 每 T 一次，转换 = 1）。
7. **结果登记**：所有实验写入 `registry/results.csv`，字段见 §9。

## 4. 工作包（按优先级排序，逐包验收）

> 每个 WP 开始前，在 `experiments/registry.md` 里写：**假设 / 预期数值 / 失败判据**（预注册）。结束后补：结果 / 是否触发停止条件。

### WP1 — 查清 CiteSeer 的 3.4 pp（最高优先级，1–2 周）

**为什么**：这是唯一明显的掉队格，也是最容易被审稿人抓的地方。

**要排查的假设**（逐个排除，写下证据）：
1. `SpikingGCN` 的 "Split I" 到底是不是 Planetoid 公开划分？去读其官方代码的 dataloader。
2. 特征是否做了行归一化（Cora/PubMed 通常做，CiteSeer 不做）？四种组合都跑一遍。
3. 隐藏维 16 对 3703 维特征是否太小？试 `{16, 32, 64, 128}`。
4. 早停是在 val 还是 test 上？确认没有信息泄漏。
5. 在他们的协议下**重跑它们的方法**（能跑就跑），给出「同协议同方法」的数字。

**验收**：
- ✅ 差距缩到 < 1 pp → 写进主表。
- ✅ 或证明是协议差异 → 写进附录，标题写「Same-Protocol Re-evaluation」。
- ❌ 都不成立 → 如实写「我们在 CiteSeer 上落后 X pp，原因待查」，并在 limitations 里承认。

---

### WP2 — 统一协议的 Pareto 表（2–3 周，决定论文能不能进主会）

**为什么**：这是 L2 的全部证据，也是「我们没有和已发表方法正面比」这条软肋的唯一解药。

**做什么**：
1. 复现至少 3 个直训方法：`SpikingGCN`、`SpikeNet`、`SiGNN`（有开源代码的优先）。**用他们的代码，套我们的协议**（同一划分、同一种子、同一 hidden）。
2. 每个方法跑满 T 网格 `{2,4,6,8,16,32}`，记录精度 / 脉冲数 / 训练时间 / 重训次数。
3. 画三条曲线：
   - `accuracy vs T`
   - `accuracy vs 每节点脉冲数`（能效代理指标，**必须注明是代理，不是实测能耗**）
   - `accuracy vs 总训练成本`（含 T 网格覆盖成本）
4. 算出**每一条方法在各精度水平下的最小 T**，做成「等精度最小时间步」大表（把现有表 5 扩成全方法）。

**验收**：转换在 `T ≤ 4` 区间不被支配；若被支配，立即记录，并触发 §7 的 Gate 2 降级路径。

---

### WP3 — 多层误差追踪（3–4 周，理论空位，最值钱）

**为什么**：现在只做 2 层，这限制了骨干、限制了深度、也限制了「够不够 A 会」的判断。这是**目前最大的理论缺口**，做完能同时解决「只有两层」和「只能用弱骨干」两个短板。

**做什么**：
1. 把恒等式推到 L 层：给出 `E_l` 的递推，判断误差是按 `∏ρ` 累积还是可被控制，给出 `T_L` 的显式依赖。
2. 在 L ∈ {2,3,4} 的 GCN 上做**反例搜索**（沿用现有流程：先找反例，再量化保守度）。
3. 若界成立，立刻把骨干换成 `GCNII-64` / `DAGNN`（Planetoid 上 ANN 可达 84–86）复跑主表——**这一步是把 Cora 从 80 推到 84+ 的唯一现实路径**。

**验收**：`L ≤ 4` 上 0 反例 + 保守度量化；或明确给出界失效的深度条件（这也是可发表的负结果）。

**失败退路**：若界在 3 层失效，转为「误差累积的经验刻画」一章，并保留 2 层主张不变。

---

### WP4 — E1 稀疏化（2 周，唯一能让你说「省电」的路）

**为什么**：现在最大的叙事短板是「不省电」。稀疏化是唯一诚实解法：不活跃单元零脉冲零误差，脉冲总数 ∝ s，Hoeffding 项按 √s 收紧。

**做什么**：
1. 训练 ANN 时对隐层加 `ℓ1` 或 `top-k` 约束，扫稀疏度 s。
2. 转换代码**一行不改**，验证 `c < 0` 自动不发放。
3. 测：脉冲数下降多少、精度下降多少、界收紧多少（`√s` 预测 vs 实测）。
4. 找 `s⋆`：波动项减半而精度不变。

**验收**：`脉冲 ↓ ≥ 40% 且精度 ↓ ≤ 0.3 pp` → **主张升级为「稀疏化后可省能」**，摘要重写。
**失败退路**：只在层一施加稀疏；再不达标就写负结果，回到「不主张省电」。

---

### WP5 — E2 多视图集成（3 周，唯一能「超过 ANN」的路）

**为什么**：整个转换文献几乎没人主张超过自己 ANN。**如果你做到，这就是摆脱「跟着 ICML'25 走」的唯一路径。**

**做什么**：
1. 三条免费扰动轴：阈值 θ、时延 T、初始膜电位。V ∈ {1,3,9}。
2. 每个视图的系统项由各自 β 抵消；按 `1/√V` 预测波动项下降；实测验证指数。
3. 判据：三个图各自 vs 自己的 ANN。
4. **必须做对照**：同 V 的「随机种子集成」作为 sanity check——如果随机集成也能涨同样多，那涨点不是你的机制，写清楚。

**验收**：≥2/3 图超过 ANN 且过噪声底 ×2 → 升级为 L3 主贡献。
**失败退路**：退回「追平 ANN + 更快 + 更少脉冲」，如实写明；同时保留「V 的收益曲线」作为负结果。

---

### WP6 — 补两个防守实验（各 3–5 天，可与上面并行）

**WP6a｜两种错位必须被实验分开（防守 ICML'25 审稿人）**
做 2×2 对照：`{层间随机置换 on/off} × {聚合内相位随机化 on/off}`。
目标：证明两种错位在图上效果**方向不同**（预期：层间置换可能小幅正面，聚合内随机化在 T≥2 明显负面）。
没有这张表，你「两种错位不是一回事」的断言就只是定义之争。

**WP6b｜同容量对决（E3）**
与直训同宽、同传播阶数。若转换落后 > 0.3 pp，把「架构解释」作为负结果写出来——**这是审稿人一定会要的那一格**。

/figures/                # 全部由脚本从 results.csv 生成

### 十条纪律
1. **先预注册再跑实验**，写清失败判据。跑完必须回填结果，包括失败。
2. **一图一脚本**：所有图表从 `results.csv` 生成，禁止手填数字。
3. **任何提升过 2×noise_floor 才算数**，否则写成「打平」。
4. **负结果必须入库**，不许「这次不算」。
5. **不许改口径**：L1/L2/L3 的措辞由人类批准后才能改。
6. `config.yaml` 里必须带 git commit；无法追溯的 run 直接作废。
7. 每周产出 `notes/weekly/W<n>.md`：本周数字、是否触发 Gate、阻塞、下周计划。
8. 单个实验超过 **24 GPU 小时**必须事先报告，不许默默烧卡。
9. **不许联网抄数字**填表；引用他人数字必须注明协议差异。
10. 遇到 Gate 不通过或方向矛盾，**停下来问人类**，不要自行降级目标。
