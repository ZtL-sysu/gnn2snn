# 协作记录协议 v1

科学目标、全量数据和验收以 PROJECT.md 指向的方案为准。本协议只管理记录和接续。各发布者使用独立 clone/worktree 和唯一 agent/<task>/<agent> 分支；不在共享脏目录 checkout/reset/stash。每个文件只有一个写入者。未明确授权不得合入main、force-push、删除远端分支或发布Release。

任务owner维护TASK，各agent只更新自己的HANDOFF、追加LOG和不可改写checkpoint。重要代码/实验/失败或交接时发布，持续工作约15–30分钟形成有意义的检查点。成功保留关键代码/原指标/必要预测，失败只同步摘要与必要小反例。复用已有权重包；数据缓存、原始私人对话、凭证、本机身份路径不公开。

metrics.csv固定列参见各checkpoint；数值和单位不得混用。SHA清单在提交前生成，input_git_head是输入HEAD而非发布提交；发布SHA从Git历史取得，避免自引用。清单只能证明文件身份，不能证明科学结论。每次push核对远端分支SHA与本地HEAD，未确认不得声称已同步。

协议实质修订必须保留旧版本、登记受影响证据并重新验收。运行中的作业必须由真实进程/job/工具handle核实，旧日志不充当活跃证据。遇到失败不删负证据、不挑seed、不降低科学门槛；仍有安全可做的独立工作则继续。
