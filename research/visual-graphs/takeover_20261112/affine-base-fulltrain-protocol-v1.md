## Separate calibration artifact

Fit 14 channelwise quantities from the unchanged teacher: abs(raw node/edge input) before layers 0–3 (8 sites), and nonnegative cumulative sums of previous ReLU node/edge branches before layers 1–3 (6 sites). The latter are accumulated branch values, not subtraction of large raw states. Use hooks with finally removal; verify each site is captured once per batch, finite and of width 70. Preserve exact quantity names and definitions. Two complete passes: channel maxima then 512-bin histograms, quantile .999 with existing ActivationHistogram semantics and positive floor. Save maxima, complete histogram counts, thresholds, rows, graph/batch counts for both passes, and provenance. Fit does not execute new coders or depend on later profile code: bind only calibrator, histogram, model/build/teacher validators, protocol and data. Profile edits therefore cannot invalidate a valid statistical fit unless its actual dependencies change.

## Fixed initial profiles

Three modes from gated_affine_base_v1.py: generic signed raw input coding at all 8 sites; first_analog exact first layer followed by 6 signed raw-input sites; centered exact first layer followed by 6 nonnegative cumulative-residual sites. Raw graded residual skips remain raw in every mode. Same analog graph readout/MLP head, no teacher hidden state fed into candidates. first_analog uses exactly the generic raw thresholds for layers 1–3. centered uses corresponding cumulative-sum thresholds. All modes use both fixed threshold multipliers 1 and 8 (six runs); 8 is the pinned generic author-code setting and 1 the common project setting. No adaptive search or favorable omission. Pinned author commit 5e0e4c73f1d0e8e17d81befa24ff947deec1f4be supplies actual MTH_diff/MTH_diff_line.

Each configuration executes one full training T4 trajectory with cumulative prefixes T1/T2/T4. Save exact source calls, scalar signed/zero/nonzero and threshold-level partitions, nonzero-row counts and cumulative prefix statistics. Capture only small prefix logits, not full activation traces. Compute separately the unchanged teacher logits for descriptive teacher-class agreement, logit MSE and teacher-to-candidate KL at each prefix; no ground-truth accuracy and no labels. Diagnostic head calls are three per batch; a normal endpoint head is once. Record this distinction and avoid using diagnostic timing as endpoint timing. All six profiles must report all 45,000 graphs/352 batches, exact nodes/edges and finite metrics. Progress at least every 50 batches.

## Predeclared conditional mechanism control

Only if a centered configuration is Pareto better than first_analog at the SAME scale on training fidelity (agreement at least as high, MSE no higher, at least one strict) AND weighted projection event count no higher at any of T1/T2/T4, run shared-threshold controls before any validation: per corresponding layer/channel theta_shared=max(theta_raw,theta_centered). Run first_analog and centered at scales 1 and 8 (four additional full training trajectories), report all four. This separates coding origin from threshold range fitting. A failure of this condition closes this particular mechanism screen without threshold tuning. Agreement/MSE are descriptive; no significance or validation selection claim.

## Cost decision and limits

For each prefix record prospective projection additions 70*sum(4*K_node + K_edge) over coded input sites, with K the nonzero scalar-event count; count source warmup/setup and graded-event handling separately. This is a shared single input stream, no old 3/2/1 branch fanout. Centered base hoisting has 7,840*N raw affine MACs plus pooled base/head costs; generic and first_analog need their own fair static-input costs. Analog sigmoid, products, normalization, BN, graph reductions, raw skips, memory/banks and head remain charged. Profile code uses dense operations and cannot establish efficient hardware/backend execution or actual energy. The prior >=5x arithmetic target stays open until full fair accounting; the old branch-fanout rejection does not automatically reject or pass this representation. A promising screen is only permission to implement and validate an actual projection cache, not a paper claim.

All official test sets have previous exposure. No new full validation/test, MNIST transfer, additional teacher seeds or secondary historical reruns are authorized by THIS narrow screen; they remain required later by the overall project scope. Negative results are retained. Final acceptance remains completed manuscript plus fresh independent CCFA review >=7, with unresolved old metric gates explicitly tracked.
