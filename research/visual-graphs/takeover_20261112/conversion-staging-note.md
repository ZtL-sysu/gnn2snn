# Full-width teacher conversion: staged prototype scope

The reference GCN has four residual branches with batch normalization and two ReLU activations in its MLP readout. `fold_teacher_bn.py` folds each eval-mode affine batch normalization into its own graph convolution while retaining the original residual addition. `full_teacher_conversion.py` applies the project's deterministic total-count idea to each of these six ReLU sites, restoring theta when decoding a rate. It tracks both the residual bypass and mean graph readout.

The initial implementation computes each downstream layer after the preceding layer's average rate is available. Thus it is a **staged rate/count numerical prototype**, not a validated parallel online spiking network: naive serialization implies six separate T-step emission windows, and real input embedding/residual paths remain analog. It does not claim T total end-to-end steps, event-driven hardware, low measured energy, or superiority over official Parallel Conversion. A true event-level implementation must be checked against it, with latency, real-valued inputs, graph weights, buffers, residual additions and readout costs recorded. Generic parallel/initialized-IF count controls may be equivalent in this staged setting.

Thresholds are currently explicit inputs; a complete calibration protocol must specify how they are estimated from the full official training split, validation selection and the exact threshold/seed budget before reporting any conversion results. The prototype is not a replacement for evaluating the user's requested full MNIST and CIFAR10 splits. Existing tests only check mathematical behavior on synthetic graphs; official test results and final conversion accuracy are not yet available.
