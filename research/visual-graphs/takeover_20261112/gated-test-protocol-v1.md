# GatedGCN full-test teacher evaluation protocol

After normal completion of the precommitted full CIFAR10 teacher training, select only its saved best-validation checkpoint and evaluate all 10,000 official PyG test graphs once in original order. Record the per-graph logits, predictions, labels, source and checkpoint hashes, epoch, split counts, environment and top-1 accuracy. Verify the best checkpoint against the completed-run hash and the recorded model implementation against its training-time hash. Refuse reuse of output files. This is a PyG adaptation of a published GatedGCN, not an exact DGL reproduction. The test set has prior project exposure and the model was selected on validation; the result is descriptive, not an untouched independent confirmation. It says nothing by itself about SNN conversion or energy.
