# Full-data public GCN teacher protocol v1

User instruction, 2026-11-12: retain the GNN-to-SNN visual research story and the previous small-teacher results as a secondary track; add published strong GNN teachers and use the entire official dataset splits. The central new experiment must not silently subsample data or use a narrow/masked network.

Reference architecture and configuration: public [Benchmarking Graph Neural Networks](https://jmlr.org/papers/v24/22-0567.html) source, pinned to repository commit `b6c407712fa576e9699555e1e035d1e327ccae6c`; the exact relevant files are preserved under `public_baselines/benchmark_*`. Four graph-convolution layers, hidden/out width 146, batch normalization, residual connections, ReLU, mean graph pooling, 146→73→36→10 MLP readout, dropout 0, no added self loops. Original DGL code uses symmetric source-out-degree / destination-in-degree graph normalization; the local PyG port must preserve the graph operator and record any source/data differences. This is a port/adaptation until verified against the original, not an official pretrained checkpoint and not a claim of replicated published accuracy.

Full MNIST SuperPixel `GNNBenchmarkDataset`: 55,000 official training, 5,000 official validation and 10,000 official test graphs; all train graphs are presented each epoch, all validation graphs evaluated. No redivision, mask, or subsampling. CIFAR10 uses its full 45,000/5,000/10,000 official split in a separately logged run. The standard test sets have been exposed to earlier project experiments and are not described as unseen independent confirmation. Select the teacher checkpoint only by validation; perform full official test evaluation only after selection, without redesigning on those test results. Save original and adapted code/config hashes, complete split identities, seed, optimizer/scheduler state, RNG state and per-epoch graph counts.

Reference optimization: seed 41, Adam lr 0.001, batch size 128, weight decay 0; ReduceLROnPlateau on validation loss (factor 0.5, patience 10), stop below lr 1e-5, capped at 200 epochs and 12 wall-clock hours for the first feasibility run. The published JSON specifies up to 1,000 epochs and a 12-hour ceiling; the cap is a real resource limit, not a claim that a 200-epoch model reproduces the reference. Fixed seeds, no selection on test. A short code/device smoke check is engineering validation only, never a reported dataset result; the actual teacher run processes complete splits.

Preferred resource is novix 4090 if immediately usable with the required data and artifacts; otherwise local `dyg-cold` and RTX 3060. Record device, actual time, completed epochs and checkpoints. A teacher target around 90% MNIST is the user's requested goal, not a fabricated result or pass already achieved. If not met, analyze full-data training and model fidelity, search another published strong teacher or verified pretrained checkpoint, and continue within the same vision/GNN-to-SNN scope. No SNN results or new manuscript claims are implied by successful teacher training.
