# Targeted novelty screen: residual-prefix shared coding

**Scope.** Bounded feasibility screen only; not an exhaustive prior-art search, novelty opinion, or final paper score. Target mechanism as supplied: for identity residual states, write `h_l=h_0+q_l` with accumulated nonnegative ReLU residual branches; hoist/cache `Wh_0+b`; code each `q_l` prefix using pinned DCGS MTH; share that coded node prefix across A/B/D/E; retain raw `q_l` on the residual skip; recompute live normalized sigmoid gates. Fixed graph and bounded conversion ticks. Treat affine hoisting, differential coding, and reuse/CSE as known primitives.

## Closest comparable mechanisms

1. **DCGS is the closest conversion-and-coding precedent, but not an exact combined invalidator on the evidence checked.** Its primary paper defines differential-coded outputs as changes in rate/activation information and derives graded units for nonlinear operations, two-input operations (including matrix products/elementwise products), differential spiking neurons, and linear layers. For a linear layer `x=W x_prev+b`, the bias can be eliminated by initializing the next membrane with `b` (or putting it in the first current); its differential linear update is driven by `W x_prev[t]`. Thus source coding before linear consumers and static affine/bias hoisting are squarely established. The checked paper describes CNNs/Transformers in this conversion section, not graph edge-normalized GatedGCN residual-prefix sharing. Primary evidence: [ICML/OpenReview paper, §4.1 and Theorems 4.2–4.5](https://openreview.net/pdf/a8ad1b41ffa7398f330ecdc19d5abbafc8f72e97.pdf); [arXiv record](https://arxiv.org/abs/2503.00301).

2. **DynaGraph is the closest shared-consumer GNN systems precedent.** Its §3.1 explicitly observes identical intermediate graph messages across GraphRNN gates and caches/reuses them across gates. This defeats any claim that “sharing one graph/message result across multiple gates/consumers” alone is new. The cached objects there are ordinary message-passing results keyed by graph and input, in dynamic/recurrent GNN execution; the paper does not describe a quantized/coded residual prefix, identity-residual origin split, or a normalized edge gate evaluated over that coded prefix. Primary evidence: [DynaGraph paper, §3.1](https://taesoo.kim/pubs/2022/guan:dynagraph.pdf).

3. **Graph-SNN residual structure exists, but is not this conversion dataflow.** The checked graph-SNN paper reports residual blocks in a trained GC-RSNN and ablates them; it discusses coding strategies, but the inspected sections do not establish ANN-to-SNN coding of nonnegative residual prefixes shared across GatedGCN projections. This means “residual graph SNN” is not a distinguishing claim. Primary evidence: [paper, §4.5](https://arxiv.org/abs/2407.20508) (residual ablation lines/section around Fig. 6).

4. **DeltaCNN / Sigma-Delta are broad delta-processing precedent.** These establish activation-difference coding and downstream updates for temporally redundant CNN inputs, so “differential coding” or event/sparse updates generally cannot carry novelty. The bounded screen did not re-open/verify the DeltaCNN equations because the CVF page fetch was blocked; Sigma-Delta was surfaced in search results and is already documented in the supplied prior-art note. Treat these as search leads here, not newly verified full-text evidence: [DeltaCNN CVPR page](https://openaccess.thecvf.com/content/CVPR2022/html/Parger_DeltaCNN_End-to-End_CNN_Inference_of_Sparse_Frame_Differences_in_Videos_CVPR_2022_paper.html); [Sigma-Delta paper](https://openreview.net/pdf?id=HkNRsU5ge).

## Remaining testable delta (candidate, not cleared novelty)

The narrow candidate is the **joint placement and state invariant**: in an ANN-to-SNN conversion of an identity-residual, edge-gated graph block, factor a fixed affine base from a nonnegative accumulated residual coordinate; apply the pinned differential MTH source to that coordinate once; feed the same coded node prefix to several distinct projection consumers while preserving an uncoded/raw skip; and keep state-dependent sigmoid-plus-graph-normalization gates live. None of the primary text inspected above documents this exact combination. This is a gap in the checked sources, not proof it is absent elsewhere. Do not claim novelty for any constituent primitive or for “shared coding” without the exact matched control.

**Concrete falsifier.** A source (paper or implementation) showing the same residual-origin/nonnegative-prefix state, coded once and consumed by multiple GatedGCN affine branches, with a raw skip and live normalized edge gate, would defeat this candidate. A graph residual quantization/coding method that sends the same quantized residual prefix to multiple projection branches would also sharply narrow or defeat it even if it is not SNN conversion.

**Minimum discriminating experiment.** At matched teacher, graph/order, MTH thresholds, horizon `T`, and head, compare: (i) per-consumer DCGS-style coding, (ii) shared generic coded source prefix with no affine residual-origin split, (iii) proposed residual-prefix shared coding, and (iv) exact analog. Add a shared-projection/CSE/cache control. Report accuracy/logit and layerwise reconstruction error, source event/nonzero-row counts, live gate/logit/normalizer/message errors, and full operation/state/memory cost. A candidate benefit is falsified if (iii) does not improve the accuracy–event/cost frontier over (ii)/(iii)'s CSE control, or if gate-normalization error grows enough to erase the claimed fidelity at the same horizon. Prototype admissibility only; no novelty clearance.
