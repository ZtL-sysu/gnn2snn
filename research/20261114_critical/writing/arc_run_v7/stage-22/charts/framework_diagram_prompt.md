# Framework Diagram Prompt

**Paper**: Critical-Site Sensitivity and Realizable Calibration in GCN-to-SNN Conversion

## Image Generation Prompt

Create a clean, academic-style methodology framework diagram for a research paper titled "Critical-Site Sensitivity and Realizable Calibration in GCN-to-SNN Conversion". The diagram should show a left-to-right data flow pipeline with these main components: Neural Network Module, Output/Evaluation. Use a professional color palette with muted blues (#4477AA), teals (#44AA99), warm yellows (#CCBB44), and soft purples (#AA3377) on a white background. Each component should be a rounded rectangle with a short label inside. Connect components with clean directional arrows. Add subtle shadows for depth. Flat vector-art style, no photorealism. High information density but visually clean. Suitable for a top-tier machine learning conference paper (ICML/NeurIPS/ICLR). Landscape orientation, 2048x1024 resolution.

## Usage Instructions

1. Copy the prompt above into an AI image generator (DALL-E 3, Midjourney, Ideogram, etc.)
2. Generate the image at high resolution (2048x1024 or similar landscape)
3. Save as `framework_diagram.png` in the same `charts/` folder
4. Insert into the paper's Method section using:
   - LaTeX: `\includegraphics[width=\textwidth]{charts/framework_diagram.png}`
   - Markdown: `![Framework Overview](charts/framework_diagram.png)`
