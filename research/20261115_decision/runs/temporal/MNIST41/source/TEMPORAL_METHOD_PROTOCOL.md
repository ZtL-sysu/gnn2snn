# Second and final bounded coding family — pre-fit registration

The first-site signed temporal codeword diagnostic admits a second coding family, not a spatial-selector retry. Both exact source orientations cover >1% of occupied training coordinates in both tasks. Preserving local T2 decode does not preserve downstream class or cost. No training diagnostic is independent success evidence.

At tick1, probe the frozen source with the known-zero next first-site current on cloned local states. Each eligible coordinate has exactly two legal representations. A causal 584-coefficient selector chooses original or alternative with score >0. Keep original source alphabet, same nonzero first-site support and two-tick local event count. First-site T2 decode is bitwise identical. Other sites and total costs remain measured outcomes. Four local probes, state copies, graph descriptor preparation, and selection arithmetic are additional overhead, charged in end-to-end timing. No teacher, labels, full-network lookahead, or future cost predictor in deployment.

Score per channel is a+b*rho+c*context0+d*context1, rho=clamped post-source membrane/theta. Four coefficients per each of 146 channels; all start zero, tie selects original. Nongraph contexts rho² and |rho|; graph contexts per-graph standardized one- and two-hop normalized message readout masses; structure-shuffled contexts jointly permuted within graph using the already fixed ID seed; TopoPIN uses standardized indegree and mean reciprocal in-neighbor indegree. These descriptors are prior controls, not claimed new. All modes have identical trainable capacity. Straight-through sigmoid selection; at local tick2 project the surrogate derivative onto q1+q2/2 constant, retaining actual source forward values. This is a stated training surrogate, not a proof of true discrete optimization.

Six arms: nongraph_local, graph_local, nongraph_decision, graph_decision, shuffled_decision, toppin_decision. Frozen strong local-T1 baseline teacher41 and its 693 offsets. Fit only new 584 selector coefficients, first fixed 128 training graphs, batch32, Adam64 updates lr.01, no clipping/best epoch/sweep. Local objective: average normalized six-site MSE across T1/T2. Decision objective: average normalized teacher logits MSE across T1/T2. Same final selector at both prefixes. Offline teacher only, delete labels before forwards. Independent exposed validation512 once per arm at T1/T2; unchanged baseline plus six arms: 28 total new endpoints. Fixed source snapshots before training, all hard training losses/gradients retained. Serial GPU, ten wall minutes per dataset including validation/timing; no restart on cap.

Admission requires on both tasks T1 accuracy at least +0.5pp over strong static local and same-capacity nongraph decision, nonworse teacher agreement, T2 accuracy drop <=0.5pp; graph advantage must survive shuffled/TopoPIN controls. Also compare previously fixed ordinary joint-logits calibration to avoid a weak reference. Actual total events, amplitude sum, and residual branch-delivery proxy must not increase at either T1/T2; neither local equivalence nor extra parameters is a free efficiency result. Bootstrap graph-paired uncertainty reported. Latency measured including local probes, copies and cache, same schedule baseline, two warm-ups/five measured repetitions. If gates fail, one implementation/alignment audit only; no optimizer/feature/data/objective/candidate tuning and no expansion to other teachers or external data. Both new coding families then close as bounded negative research, preserving the original scientific target as unachieved.
